# Gmail 发邮件组件

用主人的 Gmail 邮箱发邮件。命令是 `gmail-send`，容器里任何地方都能直接用。

## 用法

```bash
# 先看有没有配置好、发件邮箱是哪个
gmail-send --status

# 发一封邮件
gmail-send --to someone@example.com --subject "标题" --body "正文内容"

# 多个收件人、带附件、正文从文件读
gmail-send --to a@example.com --to b@example.com \
  --subject "本周报告" --body-file /workspace/reports/week.md \
  --attach /workspace/reports/week.pdf \
  --why "主人让我每周五把周报发给团队"

# 正文也可以从标准输入传
cat /workspace/notes.txt | gmail-send --to someone@example.com --subject "笔记"
```

## 规则

- 主人可以在调度台上设置"名单内免审批"或"全部免审批"。到底要不要等审批，以 `gmail-send` 运行时的提示为准；免审批也有每日封数上限，超出会改为等主人批准。
- **邮件的样子**：只给 `--body` 时，邮件会自动套一个卡片样式（彩色标题栏写标题；正文里"名称：内容"的行会把名称加粗，"【小标题】"会变成小标题，"① ② - "开头的行变成列表）。所以通知类邮件正文尽量写成一行一个"名称：内容"。
- **日报、周报这类要好看的邮件**：复制同目录下的 `邮件模板.html`，把里面的积木（标题栏、指标卡、分区卡片、列表行、进度条、"需要关注"框）填上真实内容，用 `--html-file 你的文件.html` 作为正文发出；`--body` 仍然要写一份纯文字摘要（审批时看的是它，不显示版式的邮箱也看它）。邮箱不支持网页那套排版：只用表格布局和写在标签上的 style，不能用 flex/grid、脚本、`<link>`、`<svg>`、外部图片或字体——用了会被拒绝并告诉你是哪一处。
- **发给主人自己**（收件人就是发件邮箱本身）：直接发出，不需要审批。适合日报、提醒、任务完成通知。
- **发给其他任何人**：邮件会先出现在主人的调度台上，主人看过收件人、标题、正文和附件，点了"允许"才会发出。
  命令会一直等到主人处理；15 分钟没人处理就作废。发给别人时请用 `--why` 说明为什么要发。
- 被拒绝时停下来问主人，不要换个写法再提交。
- 邮箱的登录凭据不在容器里，也不需要：发信由容器外的程序完成。

## 限制

- 收件人最多 10 个；标题最多 200 字，不能换行；正文最多 5 万字，纯文本。
- 附件最多 5 个，必须是 `/workspace/` 下的文件，加起来不超过 20 MB。
- 退出码：0 发出去了；1 没发出去（看错误信息）；3 主人没同意；4 等待超时。
